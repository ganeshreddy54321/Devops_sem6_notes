Jenkins CI/CD
1. Jenkins Introduction

Jenkins is an open-source automation server used for Continuous Integration and Continuous Deployment (CI/CD).

Features
Automated builds
Automated testing
Continuous deployment
Plugin support
2. Jenkins Architecture

12. Pipeline Stages

Downloads source code from GitHub.

Compiles application.

Test

Runs test cases.

Post Actions

Runs after build completion.
